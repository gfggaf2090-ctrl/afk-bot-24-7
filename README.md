# Discord Music Bot

بوت Discord للموسيقى مع دعم الأوامر العربية.

## المتطلبات
- Node.js 18+
- Discord Bot Tokens

## الأوامر
- `ش [اسم الأغنية]` - تشغيل أغنية
- `شغل [اسم الأغنية]` أو `play [اسم الأغنية]` - تشغيل أغنية
- `س` أو `سكب` - تخطي الأغنية
- `ق` - إيقاف الموسيقى
- `قائمة` أو `queue` - عرض قائمة التشغيل

## التثبيت المحلي
```bash
npm install
cp .env.example .env
# أضف التوكنات في ملف .env
npm start
